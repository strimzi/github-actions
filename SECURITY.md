# Security Policy

This repository follows the [Strimzi organization security policy](https://github.com/strimzi/.github/blob/main/SECURITY.md).

To report a security vulnerability, please email [cncf-strimzi-maintainers@lists.cncf.io](mailto:cncf-strimzi-maintainers@lists.cncf.io).

**Please do not file public GitHub issues for security vulnerabilities.**
